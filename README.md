# Local.Files

Десктопное приложение для прямого обмена файлами в локальной сети.

## Возможности
- Регистрация и вход по email/паролю (данные хранятся локально в SQLite).
- Автоматическое обнаружение других участников в Wi‑Fi сети.
- Передача любых файлов выбранному пользователю по TCP.
- Сохранение полученных файлов в папку «Загрузки/LocalFiles».
- Пасхалка для любопытных 😉

## Технологии
- Python 3, CustomTkinter, SQLite, сокеты (UDP + TCP)
